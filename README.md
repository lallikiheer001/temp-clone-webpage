## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/lallikiheer001/temp-clone-webpage.git
```

### 2. Navigate to the Project Directory

```bash
cd temp-clone-webpage
```

### 3. Open the Project

Open the project folder in your preferred code editor, such as Visual Studio Code.

Locate the `index.html` file and open it in your browser.

Alternatively, you can use the **Live Server** extension in Visual Studio Code to preview the webpage while making changes.
